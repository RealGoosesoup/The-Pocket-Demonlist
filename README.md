# The Pocket Demonlist 
The Pocket Demonlist is a list of the hardest levels between the length of 20-40 seconds. This is a community-maintained project <br>
You can submit records and verifications of levels on the list. Submissions are analyzed to secure legitimacy.

Special thanks to <a href="https://github.com/TheShittyList" rel="noopener">TSL</a> for the template.
